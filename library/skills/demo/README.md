## 本次真实完成了什么

1. **定稿延展**：先在 [视觉母版](source/visual-system.md) 锁定朱红圆盘、纸白/炭黑/朱红、字体层级和共享事实，再用同一套来源制作不同用途的[主海报](exports/01-main-poster.svg)、[日程卡](exports/02-program-card.svg)、[入口导视](exports/03-entry-sign.svg)。导视的箭头与短文案按远距阅读另作安排。
2. **按范围改稿**：原稿见 [history](history/)。本轮将主海报和日程卡的活动简称“开放日”改为“创作开放日”；导视保留“开放日”。两个目标的 SVG 内容哈希发生变化，导视前后哈希一致。该例外只适用于这一轮这三张。
3. **整套交付**：导出了 3 张自包含 SVG，保留 3 张修改前版本和可编辑的 [渲染源码](source/render.mjs) 与 [内容数据](source/event.json)。[manifest.json](manifest.json) 记录每张尺寸、状态、前后版本和 SHA-256。

## 如何复现

在此目录执行：

    node source/render.mjs

脚本不需要外部依赖。SVG 中的文字仍是可编辑文本，图形是矢量路径。页面显示与最终字体外观取决于本机字库；这里未声称印刷就绪。未做 CMYK、出血或实物校样检查。
