# 视觉母版：未完成的现场

这是虚构活动的公开演示，不是 Z.ONE 已发布的真实活动，也未获得用户审美采用。

## 固定

- 概念：一枚由放射线组成、中心留白的朱红圆盘。它像正在展开的作品，允许被裁切，但不换成另一套插画。
- 颜色：纸白 #F2F0E9、炭黑 #151619、朱红 #F04C36；三色各有稳定职责。
- 标题：极粗黑体、紧凑行距；英文字与数字为小号资料标签。
- 共用事实只从 event.json 读取。所有物料必须有“虚构演示”标识。

## 按用途变化

- 主海报：先看主题和视觉，再读活动名、时间、地点。
- 日程卡：活动名和三个时段优先，圆盘缩小让出扫描空间。
- 入口导视：远距识别优先，使用短称“开放日”和大箭头。

## 本轮例外

将主海报和日程卡上的活动简称“开放日”改为“创作开放日”。入口导视保留短称“开放日”，因为它用于远距识别。本轮仅改这三张的当前版本，不建立以后所有活动都适用的规则。
